CLOSE THE GAPS.

Four weaknesses.
A stronger foundation.

After a fictional social media company’s data breach, four known weaknesses need attention. A risk assessment that connects each gap to a practical control and a way to verify the change.

01 / Identity

Shared employee passwords

+

Shared credentials weaken accountability and expand the impact of a leaked password.

Recommended control
Individual accounts, unique secrets, least privilege and a clear prohibition on credential sharing.
Verification plan
Review the account inventory and access logs; confirm actions map to named users and retire shared credentials.
02 / Privilege

Default database admin password

+

A known default secret makes privileged access easier to guess.

Recommended control
Rotate the default secret, store it securely, restrict administrative access and review privileged accounts.
Verification plan
Confirm the default no longer works through an authorized check, and review administrative access permissions.
03 / Network

Unfiltered traffic

+

Missing ingress and egress rules leave unnecessary communication paths open.

Recommended control
Document required flows, use a default-deny policy with explicit exceptions, log decisions and review changes.
Verification plan
Test approved services and blocked paths from authorized test points; review logs for unexpected drops or allows.
04 / Authentication

No multifactor authentication

+

A stolen or guessed password may be enough to access an account.

Recommended control
Prioritize phishing-resistant MFA for privileged and remote access, then expand coverage with secure recovery.
Verification plan
Verify enforcement, enrollment and recovery; confirm password-only access is rejected where MFA is required.

01 / Scope and risk

Protect the information.
Account for the unknowns.

The organization has already experienced a data breach. Shared employee passwords, a default database administrator password, missing firewall rules and absent MFA are the supplied findings. The assessment covers identity, privileged access and network traffic controls.

Potential consequences include unauthorized access, weak attribution, data exposure and repeated compromise. Likelihood and impact cannot be quantified from this narrative alone: there is no topology, asset inventory, access log, breach timeline or control test result.

03 / Validation and ownership

A plan that can
be checked.

  1. 01Assign responsibility

    Appoint owners for identity, database administration and firewall policy. Agree priorities, review dates and an exception process with management.

  2. 02Roll out carefully

    Plan credential rotation and MFA recovery to avoid accidental lockout. Test firewall changes against required business flows before broad deployment.

  3. 03Validate and maintain

    Use the verification plan for each gap. Document evidence, unresolved exceptions and corrective actions. Scope and authorize any penetration test before it begins.

A successful assessment should lead to traceable decisions and repeatable review. This training deliverable proposes that workflow; it does not claim the organization’s network is now secure.

Part 2: Explain your recommendations

The organization should establish firewall rules to filter incoming and outgoing network traffic. Only necessary and authorized connections should be allowed, while potentially dangerous or suspicious traffic should be blocked. Firewall configurations should also be reviewed and updated regularly to address new security threats.

Implementing MFA would add another layer of security by requiring users to verify their identity using a second authentication method, such as an authenticator app or security key. Even if an attacker obtains an employee's password, MFA can prevent them from accessing the account without the additional verification.

I would recommend conducting regular penetration tests to identify additional security vulnerabilities within the organization's network. The security team can then use the findings to prioritize updates, apply security patches, and fix weaknesses to minimize the attack surface and reduce the risk of future attacks and data breaches.

Conclusion:

Implementing firewall rules, MFA, and regular penetration testing will strengthen the organization's security, reduce vulnerabilities, and help prevent future attacks and data breaches.
